Aida — stitch & clay studio

A supervisor agent routes to four specialists (pattern conversion, stitch coaching, recommendations, clay). Photos become DMC charts with Lab clustering and CIEDE2000 matching, then a human approves the palette before the graph continues. Clay lessons are grounded in a local pack so the model cannot invent kiln facts.

  • Deterministic image-to-pattern pipeline — the LLM never invents floss codes
  • Human-in-the-loop interrupt on palette approval
  • SSE from Python to the Next.js UI; API keys stay on the server
